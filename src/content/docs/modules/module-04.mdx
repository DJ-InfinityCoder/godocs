## Functions in Go

A function is a reusable block of code that performs a specific task.

```go
func add(a int, b int) int {
    return a + b
}
```

**Calling:**

```go
result := add(10, 20)
fmt.Println(result) // 30
```

### Node.js Comparison

```javascript
function add(a, b) {
    return a + b;
}
```

**Main difference:** Go explicitly specifies parameter types and the return type.

## Multiple Return Values

Go functions can return multiple values, commonly a result and an error.

```go
func divide(a int, b int) (int, error) {
    if b == 0 {
        return 0, fmt.Errorf("cannot divide by zero")
    }
    return a / b, nil
}
```

**Calling:**

```go
result, err := divide(10, 2)
if err != nil {
    fmt.Println(err)
    return
}
fmt.Println(result) // 5
```

In JavaScript you would typically return an object or use callbacks/promise which is less idiomatic for error handling.

## Ignoring a Return Value with `_`

```go
result, _ := divide(10, 2) // ignore error
```

The blank identifier tells the compiler you intentionally discard the value.

## Variadic Functions

A variadic function can accept zero or more arguments of a given type.

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}
```

**Usage:**

```go
fmt.Println(sum(1, 2))            // 3
fmt.Println(sum(1, 2, 3, 4, 5)) // 15
```

JavaScript equivalent uses the rest operator:

```javascript
function sum(...nums) {
    return nums.reduce((a,b)=>a+b,0);
}
```

### Passing a Slice to a Variadic Function

```go
nums := []int{1,2,3,4}
fmt.Println(sum(nums...)) // 10
```

## Anonymous Functions (IIFE‑like)

```go
func() {
    fmt.Println("Hello")
}() // immediately invoked
```

You can also assign to a variable:

```go
greet := func(name string) {
    fmt.Println("Hello", name)
}

greet("Dilip")
```

## Passing Functions as Arguments

Functions are first‑class values in Go.

```go
func calculate(a int, b int, op func(int,int) int) int {
    return op(a,b)
}

result := calculate(10,20, func(a,b int) int { return a+b })
fmt.Println(result) // 30
```

Similar to callbacks in JavaScript.

## Methods

A method is a function with a *receiver* tied to a type.

```go
type User struct {
    Name string
}

func (u User) greet() {
    fmt.Println("Hello", u.Name)
}
```

**Calling:**

```go
user := User{Name: "Dilip"}
user.greet() // Hello Dilip
```

### Value Receiver vs Pointer Receiver

```go
// Value receiver – receives a copy
func (u User) changeName() {
    u.Name = "Rahul"
}

// Pointer receiver – can modify the original
func (u *User) changeNamePtr() {
    u.Name = "Rahul"
}
```

```go
u := User{Name: "Dilip"}
 u.changeName()       // no change
 fmt.Println(u.Name) // Dilip
 u.changeNamePtr()    // modifies
 fmt.Println(u.Name) // Rahul
```

**Rule of thumb:** Use value receivers for read‑only behavior, pointer receivers when you need to modify the receiver or avoid copying large structs.

## Structs

Structs group related fields.

```go
type User struct {
    Name  string
    Age   int
    Email string
}

user := User{Name: "Dilip", Age: 21, Email: "dilip@example.com"}
fmt.Println(user.Name)
```

## Struct Embedding (Composition)

Go favors composition over inheritance.

```go
type Address struct {
    City  string
    State string
}

type User struct {
    Name string
    Address
}

u := User{Name: "Dilip", Address: Address{City:"Delhi", State:"Delhi"}}
fmt.Println(u.City) // field promotion
```

## Anonymous Structs

Useful for quick, one‑off data structures.

```go
resp := struct {
    Status string
    Count  int
}{
    Status: "success",
    Count:  10,
}
```

## Struct Tags (Metadata)

Tags add metadata used by libraries (e.g., JSON, DB). Example for JSON:

```go
type User struct {
    ID    int    `json:"id"`
    Name  string `json:"name"`
    Email string `json:"email,omitempty"`
    Pass  string `json:"-"`
}
```

- `omitempty` omits the field when it has a zero value.
- `json:"-"` completely excludes the field from JSON output (useful for passwords).

Different libraries use their own tags (`db`, `bson`, `validate`, etc.).

## Strings in Go

Go strings are immutable UTF‑8 sequences.

```go
name := "Dilip"
fmt.Println(name)
```

The `strings` package provides many utilities:

- `strings.Contains(s, substr)`
- `strings.HasPrefix(s, prefix)`
- `strings.HasSuffix(s, suffix)`
- `strings.ToUpper(s)` / `strings.ToLower(s)`
- `strings.TrimSpace(s)`
- `strings.Split(s, ",")`
- `strings.Join(parts, " ")`
- `strings.ReplaceAll(s, old, new)`
- `strings.Index(s, substr)`

## Bytes and Runes

Convert between string and byte slice:

```go
b := []byte("Hello")
fmt.Println(b) // [72 101 108 108 111]

s := string(b)
fmt.Println(s) // Hello
```

A *rune* is an alias for `int32` and represents a Unicode code point.

```go
var ch rune = 'अ'
fmt.Println(ch) // Unicode code point
```

When dealing with multibyte UTF‑8 characters, use `[]rune` to count characters correctly.

## Time Package

```go
now := time.Now()
fmt.Println(now)
```

Create a specific time:

```go
t := time.Date(2026, time.September, 11, 10, 30, 0, 0, time.UTC)
```

Formatting uses the reference date `Mon Jan 2 15:04:05 MST 2006`:

```go
fmt.Println(now.Format("2006-01-02")) // 2026-09-11
```

Parsing:

```go
t, err := time.Parse("2006-01-02", "2026-09-11")
```

Load a location for time‑zone aware operations:

```go
loc, _ := time.LoadLocation("Asia/Kolkata")
localTime := now.In(loc)
```

Durations are expressed using constants:

```go
elapsed := time.Since(start)
fmt.Println(elapsed)
```
